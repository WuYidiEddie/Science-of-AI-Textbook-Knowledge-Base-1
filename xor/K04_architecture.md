# K04 架构：容量与 LN 主导；residual 在短训区间可能变差

## 结论

### A. 受控探针（SUP-D，one-at-a-time）

固定：XOR 实例 2 个，Adam lr=3e-4，steps=512，bs=32，基线 `d=2,w=48,mask=[0,0],res=False,act=relu`。

| 改动 | CE 相对基线（两实例） | 方向 |
|---|---|---|
| 宽 48→128 | 0.57× / 0.59× | **更好** |
| LN 两层 | 0.50× / 0.70× | **更好** |
| 深 2→3 | 0.62× / 0.82× | **更好** |
| LN 一层 | 0.68× / 0.72× | 更好 |
| act=leaky_relu | 0.90× / 0.97× | 略好 |
| act=gelu | 0.99× / 1.07× | 近似持平 |
| res=True | 1.18× / 1.31× | **变差** |
| act=silu | 1.34× / 1.47× | 变差 |
| 深 2→1 | 2.09× / 2.05× | 明显变差 |
| 宽 48→16 | 3.30× / 3.60× | 最差 |

**可下的受控结论**：在该短训区间，**容量不足（过窄/过浅）是最大风险**；加 LN 稳定有益；**residual 并非免费午餐**，在此协议下平均变差约 20–30%。

### B. 题面观察性对比（M 的 fill_qctx，17 道 architecture_only）

同一题内 3 选项共享 opt/lr/steps/bs，只比架构。对 51 个架构对统计胜者特征：

- 更多 LN：71.1%（27/38）
- 更深：69.2%（27/39）
- gelu：68.2% 胜率；silu 仅 33.3%
- res=True：60.7%（17/28）
- 更宽：仅 41.4%（即题面里更宽并不占优）

观察性结果与受控探针在 **LN / 深度 / silu 弱** 上一致，但在 **宽度、residual** 上冲突：题面三选项是联合设计（宽、深、LN、res、act 相关），**不能**把胜率读成因果。冲突时以 A 为准。

## 适用范围

- A：上述 2 个 XOR 实例、Adam 3e-4、512 steps、bs=32、3 seeds、无 wd
- B：`fill_qctx_v1` 覆盖的 17 道 XOR `architecture_only` 题，5 seeds×约 2 次重复，指标 = mean final CE
- 任务：XOR 测试 CE，输出维 2

## 证据

- SUP-D：`experiments/xor/_analysis_tmp/supp_results.jsonl` 中 `exp=D_arch`（22 行）
- B：`measured/measured.jsonl` 中 `src=fill_qctx_v1`；逐题排序见 K05

## 边界（不保证）

- **不**声称全局“越深越好/越宽越好”：深度只测了 1/2/3，宽度只测了 16/48/128；更深（≥8）或超宽可能过拟合或难训。
- **不**外推 residual 到长训、大模型、Transformer；残差在深网/长训里通常有益，这里的“变差”只在 **浅网+512 steps+XOR** 成立。
- act 排序（leaky≈gelu≈relu > silu）只在该基线附近成立；题面里 silu 也偏弱，但机制未分离。
- mask/LN 的“位置”效应（LN 放第几层）未做完整析因。

## 实用含义

- 题目若让在“窄浅”和“宽/深+LN”之间选，短训 XOR 上应选后者。
- 不要因为“有残差”就自动加分；应看该预算下是否还在欠拟合区。
