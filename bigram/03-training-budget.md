# bigram · 03 训练预算（步数）与交互

指标：test CE（越低越好）。“步数”指 `training_steps`；`total_samples_seen = steps × bs`。

---

## B-BUD-01 在 E9 常规网格里，更多步数通常更好

### 结论陈述

固定 `(ds, kind, d, w, dff, opt, lr, bs)`，只改 `steps ∈ {64, 256, 1024}`：

| 对比 | 胜率 | 说明 |
|---|---:|---|
| 256 > 64 | 199/279 ≈ **71%** | 平均优势 ~0.11 CE |
| 1024 > 256 | 193/279 ≈ **69%** | 平均优势 ~0.11 CE |
| 1024 > 64 | 174/279 ≈ **62%** | 优势被反例稀释 |

argmin（哪一步数最好）：**1024 最好 193/279 = 69%**，256 好 51 次，64 好 35 次。

TF 与 GRU 方向一致（tf：1024>256 约 68%；gru：约 69%）。

### 适用范围

- **指标**：test CE（越低越好）  
- **数据**：V24a1 / V32a1 / V48a14（E9）
- **lr**：网格混合；在 **lr=1e-4** 附近时几乎总是步数越多越好（256>1024 为 0/45）
- **kind**：tf 与 gru 都成立
- **bs**：16

### 范围外不要用

- lr=3e-3/1e-2 的不稳区（见 B-BUD-02/03）
- 未测 2048+（E12 有补测行，主结论用 E9）

### 实务含义

预算题若其他都相同：**通常选 steps 更大的选项**，但必须确认 lr 不在危险区。

## B-BUD-02 在 cliff 题面数据 + Adam + 中高 lr 下，更少步数反而更好

### 结论陈述

E25 cliff（9 个题面 qid 数据集），固定 `(ds,V,kind,d,w,dff,opt,lr,bs)`：

- **256 > 1024：89/90 ≈ 98.9%**（Wilson \([0.94, 0.998]\)）
  - 全部发生在 **Adam**，lr ∈ {1e-3, 3e-3}
- **1024 > 2048：239/360 ≈ 66.4%**（\([0.61, 0.71]\)），平均优势 ~0.55 CE
- 256 相对更长预算的平均优势可达 **0.59–1.72 CE** 量级（见 `_analyze_summary2.json`）

### 适用范围（写死）

| 维度 | 值 |
|---|---|
| 数据 | e25 的 9 个 qid 集（q_a12ca6, q_19ea7d, q_bc0028, q_0f8a5a, q_cdaa55, q_221346, q_21720d, q_2af6e5, q_5fdac6） |
| 优化器 | 对 256 vs 1024 的干净对照仅 **Adam** |
| lr | 1e-3 或 3e-3 |
| steps | 256 vs 1024 vs 2048 |
| 形状 | cliff 网格（tf/gru，d∈{1,2}，w∈{32,64,128} 等） |

### 范围外不要用

- **不要**推广到 V24/V32/V48 + Adam + 1e-4（那里 256>1024 为 0/45）。
- 不要推广到 SGD@0.01（E9 中大 lr 的 SGD 往往需要更多步）。
- 不要写成“短训永远更好”。

### 实务含义

题面预算若写 256 vs 1024/2048，且优化器是 Adam、lr 在 1e-3–3e-3：**短预算可能已经落在更优点**，长预算可能过冲/震荡。这是“步数与 lr 交互”，不是步数本身的主效应。

## B-BUD-03 “训练越久越好”在 bigram 任务族不成立

### 结论陈述

把 B-BUD-01 与 B-BUD-02 合在一起，更准确的表述是：

> 最优步数是 **(数据, 优化器, lr) 的函数**，不是单调函数。  
> 低 lr（~1e-4）→ 更多步更好；中高 lr（1e-3–1e-2）+ Adam → 更少步更好或持平；错误 lr 下增加步数经常放大损失。

E9 中 256 反超 1024 的频率随 lr 变化（256 vs 1024，按 lr 的 256 胜场/总组数）：

| lr | 256 胜 / 组数 |
|---:|---:|
| 1e-4 | **0 / 45** |
| 3e-4 | 9 / 45 |
| 1e-3 | 27 / 45 |
| 3e-3 | 29 / 45 |
| 1e-2 | 21 / 45 |
| 3e-2 | 0 / 9 |

### 适用范围

E9 + E25 并集上的定性交互规律；具体数字以各表为准。

### 实务含义

选择题里出现 “steps A vs steps B”：

1. 先看 lr 与优化器；
2. 低 lr → 选更大 steps；
3. 中高 lr + Adam → 不要自动选更大 steps；
4. margin 小则按刀刃局处理（`05-noise-and-confidence.md`）。

## 附：cliff 里固定 lr 的优化器反直觉排序（与步数耦合）

在 cliff 固定 lr 时：

- Adagrad 成对大幅胜出（margin ~1.3）
- SGD 也常胜 Adam 族（margin ~1.2）
- 同时 **steps: 256 > 1024 > 2048**

一种自洽解释（**解释，不是直接测量**）：这些 qid 数据 + 中高 lr + Adam 长训会进入高 loss 区；短训或自适应更保守的 Adagrad 更安全。  
选用结论时请引用现象与范围，不要把该解释写成定律。
