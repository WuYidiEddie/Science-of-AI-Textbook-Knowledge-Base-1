# C01 · 训练语境（优化器 × 学习率）决定成败量级

## 结论

在 spiral 二分类 + ArchitectureIQ MLP 协议下，**固定架构时，换 (optimizer, lr) 可以让 test CE 从 ~1e-4 变到 ~0.70，跨度约 4 个数量级**；同一语境内再改深度/宽度/LN/激活，典型跨度只有 1–3 个数量级，且多数落在“已成功”或“已失败”一侧。  
因此：**解释或预测绝对 loss 时，训练语境是一等公民；架构只能做语境内排序。**

## 适用范围

- 数据：`spiralcls_8585ec`（n=1024/2048，平衡二分类，xstd≈2.9）
- 架构：`d=4, w=64, mask=[1,1,1,1], res=True, act=silu`
- 预算：`steps=256, bs=32, wd=0`
- 优化器：`{Adam, AdamW, RMSprop, Adagrad, SGD}` × `lr ∈ {3e-5, 1e-4, 3e-4, 1e-3, 3e-3}`
- 指标：test CE，3 seeds 均值
- 来源：`supplement/controlled_grid.jsonl` 因子 `opt_x_lr`
- 「架构跨度 1–3 个数量级」一句对照的是 **同文件** 的 `depth_x_width` / `ln_mask` / `act` / `residual` 因子（同一实例、Adam 甜区附近），不是任意架构空间

## 证据

| (opt, lr) | test CE | 相对最好 |
|---|---:|---:|
| Adam / AdamW @ 3e-3 | 3.5e-5 | 1× |
| RMSprop @ 1e-3 | 1.1e-4 | 3× |
| Adam / AdamW @ 1e-3 | 2.7e-4 | 8× |
| Adam @ 3e-5 | 0.341 | 1.0e4× |
| SGD @ 3e-5 | 0.705 | 2.0e4× |

同因子内极差：`0.705 / 3.5e-5 ≈ 2.0×10⁴`。  
对照：同语境下 `depth×width` 极差约 `1.6×10⁴`，但其中最差点（d=1,w=16）本身就是容量不足；在“可训”子集（d≥2 或 w≥64）内极差降到约 10²–10³。  
`act` 在同语境下仅 1.2×，`residual` 约 1.5×。

source 银行（同实例、7 个语境）也支持：  
`RMSprop|0.001|x256|b32` 中位 CE=0.00042，`Adam|3e-05|x256|b32` 中位 CE=0.428，相差约 **1000×**，而每组内 26 个架构的最大差通常不到 100×。

## 边界

- 只覆盖上述 5 个优化器的默认 β/ε，不覆盖 Adam 变体、学习率调度、warmup、梯度裁剪。
- `steps=256` 是短预算；更长训练会缩小但 **不会抹平** 小 lr 的劣势（见 C05）。
- 不覆盖回归族、XOR、大模型或真实数据集。
- “语境优先”不等于“架构无关”：在坏语境里架构排序仍可做（C06），只是绝对值不可比。

**证伪条件**：若在同一实例上，固定 (opt,lr) 的架构极差稳定大于更换 (opt,lr) 的极差（同为 3 seeds 均值、同网格），则“语境决定成败量级”被证伪。
