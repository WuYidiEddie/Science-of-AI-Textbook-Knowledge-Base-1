# C08 · 种子方差在成功区很小，3 seeds 足够区分数量级

## 结论

在本协议的 98 个控制配置上（每配置 3 seeds）：

- **绝对种子标准差** 中位仅 **6.6e-5**（CE 本身常在 1e-4 量级）。
- **相对种子标准差**（std / mean CE）中位 **14%**，均值 15%，p90 **23%**。

可操作规则：

1. 比较差 **≥ 3×** 的两配置时，3 seeds 通常够用。
2. 比较同量级刀刃局（CE 比 < 1.5×）时，要么加到 5–10 seeds，要么标低置信，**不要写死规律**。
3. 成功区（CE<1e-3）里排名非常稳；近先验区（CE≳0.6）排名会被种子噪声推动，结论要降级为“趋势”。

## 适用范围

- 来源：`supplement/controlled_grid.jsonl` 全部 98 配置 × 3 seeds
- 配置覆盖：opt×lr、depth×width、ln_mask、residual、act、instance、steps、bs、wd
- 种子：`torch.manual_seed(0,1,2)`，数据划分固定
- **不含** 数据重采样、初始化大范围扰动、GPU 非确定性带来的额外方差

## 证据

| 配置示例 | finals（3 seeds） | 相对极差 |
|---|---|---|
| Adam 3e-3 基线 | [4e-5, 3e-5, 3e-5] | 很小 |
| d5_w256 | [2e-5, 2e-5, 1e-5] | 很小 |
| d1_w16 | [0.175, 0.227, 0.310] | ~1.8× |
| fa00ef good_adam | [0.095, 0.015, 0.009] | **~10×（刀刃/未收敛）** |
| d7a0dc good_adam | [0.487, 0.522, 0.435] | 较小但 CE 高 |

measured 的 `finals`（3 或 5 seeds）同样显示：成功行相对 std 低，失败/临界行相对 std 高。

## 边界

- 只有 3 seeds，对 **方差本身的估计** 很粗糙；p90=23% 不能当成精确分位数。
- 未测 5/10 seeds 下刀刃局的翻转率。
- CPU/GPU、PyTorch 版本、`torch.backends.cudnn.deterministic` 未统一记录；换环境绝对数可能漂移。
- 相对 std 在 CE→0 时会爆炸（分母小）；看绝对 std 更稳。

**证伪条件**：若在成功区（CE<1e-3）的配置上，3-seed 相对 std 中位数稳定 >40%，或差距 ≥3× 的两配置经常被 3 seeds 翻转，则“3 seeds 够用”被证伪。
