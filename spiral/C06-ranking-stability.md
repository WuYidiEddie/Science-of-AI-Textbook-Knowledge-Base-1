# C06 · 架构相对排序跨训练语境稳定，绝对 loss 不稳定

## 结论

在 source 银行（同一实例 `spiralcls_8585ec`，26 个共享架构，7 个训练语境）上：

1. **架构排序高度稳定**：语境两两 Spearman ρ 均值 **0.93**（最低 0.82，最高 0.99）。
2. **绝对 test CE 不稳定**：同一架构换语境可差 10²–10³ 倍。

因此可以写：

- “在本协议的多种 (opt,lr,steps,bs) 下，架构 A 的相对排名通常优于 B” —— **可写**
- “架构 A 的 test CE 是 0.001” —— **必须绑定语境**，否则无意义

## 适用范围

- **数据**：supplement/controlled_grid.jsonl + measured/source 排序对照  
- 数据：仅 `spiralcls_8585ec`
- 26 个在全部 7 个语境都出现过的 (d,w,mask,res,act)
- 7 个语境：  
  `RMSprop|1e-3|x256|b32`、`Adagrad|3e-3|x256|b16`、`Adagrad|1e-3|x256|b32`、  
  `Adam|1e-4|x256|b16`、`Adam|3e-5|x256|b32`、`AdamW|3e-5|x512|b64`、`AdamW|3e-5|x1024|b32`
- 指标：每个语境内对 26 架构的 test CE 做 Spearman

## 证据

- 平均 ρ = 0.929；RMSprop 语境与其它语境略低（0.82–0.91），自适应弱 lr 语境之间 0.95+。
- 各语境下“最好架构”都落在 **深 + 宽 + 有 LN + 常带 residual + gelu/silu** 那一角：  
  例如多个语境最优是 `d=4,w=256,ln=3,res=True,act=gelu`。
- 但绝对中位 CE：`RMSprop|1e-3` → 0.00042，`Adam|3e-5` → 0.428。

## 边界

- 只有 7 个语境、1 个数据实例；不能声称“所有优化器都同序”。
- ρ 0.82–0.99 仍有错序；**三选项刀刃局**（CE 差 < 种子噪声）不能靠跨语境共识硬判。
- 语境网格本身偏向“都能训一点”的区域；若加入完全炸掉的 lr，排序可能被噪声打乱。
- 不覆盖回归族；univar/mvar/tabular 的跨语境 ρ 未在此计算。

**证伪条件**：若在同 26 架构上，任意两个测过语境的 Spearman ρ 稳定 <0.7，或“每语境最优都落在深+宽+LN+res+gelu/silu”出现反例（某语境最优是浅/窄/无 LN/relu），则对应条款被证伪。
