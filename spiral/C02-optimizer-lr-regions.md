# C02 · 各优化器的可用学习率区域

## 结论

在 C01 的协议与架构下，要把 test CE 压到 **≤ 0.01**，各优化器需要的 lr 量级不同：

| 优化器 | 能到 CE≤0.01 的 lr | 推荐单点 | 未达标区域 |
|---|---|---|---|
| Adam | ≥ 3e-4 | **1e-3**（CE≈2.7e-4）；3e-3 更低（3.5e-5） | ≤ 1e-4 明显欠训 |
| AdamW | 与 Adam 在 wd=0 时 **逐点相同** | 同 Adam | 同 Adam |
| RMSprop | ≥ 3e-4 | **1e-3 或 3e-3**（≈1e-4） | ≤ 1e-4 欠训 |
| Adagrad | ≥ 1e-3 | **3e-3**（≈1.5e-3） | ≤ 3e-4 远未收敛 |
| SGD（mom=0） | 在 lr≤3e-3 内 **未达标** | 3e-3 仅到 0.14 | 需要更大 lr 或 momentum |

经验规则（仅限本协议）：**自适应方法从 lr≈1e-3 起试；SGD 在这个 lr 网格里不够用。**

### 做题决策顺序：先排 (opt,lr)，再比架构

上表 CE 差是数量级级的（Adam@1e-4≈0.044 vs SGD@3e-3≈0.14 vs Adam@3e-5≈0.34），**远大于**架构/激活/wd 的常规效应（C07：成功区 wd≥1e-3 也只 35× 相对项，但绝对 CE 仍在同一「未达标」带内比）。mixed 题不要先被「架构更齐整」吸引。

- **反例（题对齐）**：`q_682517` 赢家是 **AdamW@1e-4**（表内 0.044 档），胜 SGD@3e-3 的大架构包——即便赢家带 wd=1e-3，(opt,lr) 差仍压过架构。  
- **用法**：  
  1. 淘汰 SGD@≤3e-3（表内未达标）与任何 opt@≤1e-4 里更差的一侧（Adam@3e-5 最差）。  
  2. 在剩余可用/半可用 (opt,lr) 内再比深度/宽度/LN。  
  3. 两侧都「欠训」时选 **CE 矩阵更靠左上** 的一侧，而不是架构分更高的一侧。

## 适用范围

- **指标**：test CE；**数据**：spiralcls_8585ec + C01 协议网格  
- 同 C01：`spiralcls_8585ec`，`d=4,w=64,all-LN,silu,res=True`，`steps=256,bs=32,wd=0`
- lr 网格：`{3e-5, 1e-4, 3e-4, 1e-3, 3e-3}`（**不是连续扫参**）
- SGD 的 `momentum=0`；未测 momentum>0
- AdamW 与 Adam 重合 **只在 wd=0 时** 成立；有 weight decay 时二者不同

## 证据

CE 矩阵（rows=优化器, cols=lr）：

```text
opt\lr      3e-05     0.0001     0.0003      0.001      0.003
Adam        0.34131    0.04373    0.00273    0.00027    0.00003
AdamW       0.34131    0.04373    0.00273    0.00027    0.00003
RMSprop     0.21933    0.01092    0.00059    0.00011    0.00011
Adagrad     0.66332    0.53974    0.28599    0.02479    0.00146
SGD         0.70477    0.66271    0.57739    0.39283    0.13957
```

source 在同一实例上的语境中位数与此一致：  
`RMSprop|0.001` → 0.00042；`Adagrad|0.001` → 0.048；`Adam|3e-05` → 0.428。

## 边界

- 只测了 5 个 lr 点；不能说 “3e-3 一定优于 1e-3”（两者都已到噪声底，CE 3.5e-5 vs 2.7e-4 的差可能部分来自收敛残差）。
- 不覆盖 Adam 的 `(β1,β2,ε)`、RMSprop 的 `α`、Adagrad 的 `lr_decay`。
- 不覆盖学习率衰减 / cosine / warmup。
- SGD+momentum、更大 lr、更多 steps 下的 SGD 表现未知。
- 换到难实例（xstd≈8）时，**同一 lr 的绝对 CE 会差很多**（C05），但“需要 lr≥1e-3”这条相对结论仍大致成立。

**证伪条件**：若在同一实例+同架构下，Adam 在 lr=3e-4 或 1e-3 稳定达不到 CE≤0.01，或 SGD mom=0 在 lr≤3e-3 稳定达到 CE≤0.01，则对应行被证伪。
