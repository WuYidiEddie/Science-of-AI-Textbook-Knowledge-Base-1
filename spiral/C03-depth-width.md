# C03 · 深度是瓶颈，宽度是加速器

## 结论

在 C01 协议（Adam lr=1e-3, steps=256, bs=32, all-LN, silu, residual）下：

1. **d=1 是硬瓶颈**：即使 w=256，test CE 仍为 0.0036；d=1,w=16 到 0.237。
2. **d≥3 且 w≥64 时进入 CE≤5e-4 区**；`d=5,w=256` 最低（1.5e-5）。
3. 在固定深度下加宽几乎单调改善；在固定宽度下加深也几乎单调改善；二者可互换“补容量”，但 **浅而宽补不满深而窄的差距**（d=1,w=256 = 0.0036 vs d=4,w=32 = 0.0010）。

粗略预算规则（仅本协议）：

| 目标 test CE | 起步配置 |
|---|---|
| < 0.05 | d≥2, w≥32 或 d=1,w≥128 |
| < 0.001 | d≥3, w≥64 |
| < 1e-4 | d≥4, w≥128 或 d=5,w≥64 |

## 适用范围

- 数据：`spiralcls_8585ec`
- 固定：`Adam lr=1e-3, steps=256, bs=32, wd=0, mask=全 LN, res=True, act=silu`
- 网格：`d ∈ {1..5}, w ∈ {16,32,64,128,256}`，每点 3 seeds
- 指标：test CE

## 证据

```text
d\w         16         32         64        128        256
  1    0.23740    0.08918    0.02746    0.01064    0.00361
  2    0.04488    0.00867    0.00203    0.00069    0.00026
  3    0.00949    0.00284    0.00053    0.00019    0.00007
  4    0.00361    0.00104    0.00027    0.00007    0.00003
  5    0.00225    0.00051    0.00016    0.00005    0.00002
```

source 在 7 个语境内也一致：`d=4/5` 的中位 CE 普遍比 `d=1` 低 1–2 个数量级（例如 `Adam|3e-05` 语境：d=1 → 0.691，d=5 → 0.240）。

## 边界

- 深度 1–5、宽度 ≤256；**不外推到 d=10+ 或 w=4096**。
- 所有点都开了全 LayerNorm + residual + silu；无 LN 或 relu 时矩阵会整体变差，但排序大体同向。
- 这是 **短预算（256 步）** 下的容量-优化联合结果；更长训练会让窄浅网追近，但 source 显示 d=1 在 256–1024 步内仍差。
- “更深更好”在本螺旋几何上成立；**不自动迁移到 tabular**（现有 playbook 里 tabular 深浅接近对半）。
- 只看 test CE，不涉及泛化间隙、参数量效率或推理成本。
- **低 lr 下 d=1 vs d=2 的差距可被宽度翻转**（2026-10-27 补）：本条「d=1 硬瓶颈」在 Adam lr=1e-3 + 全LN + res + silu 下测得。题对齐反例：`q_1d5fc3`（Adam@3e-5，256×32）赢家是 `d=1,w=24,1LN`，胜 `d=2,w=16,1LN,res`——极低 lr 时 w=16 的容量惩罚超过深度红利。**用法**：「d=1 硬瓶颈」在 lr≤3e-5 或 w≤16 时降级为强负项；宽度差 ≥8 或 lr 差 ≥2 档时须重算。

**证伪条件**：同协议下若 d=1,w=256 稳定优于 d=4,w=32，或 d≥3,w≥64 无法进入 CE≤5e-4，或 d=1,w=256 与 d=5,w=256 差距 <2×，则对应条款被证伪。
