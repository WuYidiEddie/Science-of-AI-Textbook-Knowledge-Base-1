# C04 · LayerNorm 的位置比“开几个”更重要

## 结论

在 d=4 的 MLPBlock 堆栈里，**LN 放在靠前的块（左端）比放在靠后（右端）更有效**；只要左端有 1–2 个 LN，再往后加 LN 的收益很小，甚至全开不一定最好。

排序（同一协议下 test CE，越低越好）：

```text
ln2_left [1,1,0,0]  0.000203   ← 最好
ln3      [1,1,1,0]  0.000208
ln1_left [1,0,0,0]  0.000216
ln2_alt  [1,0,1,0]  0.000246
ln4      [1,1,1,1]  0.000266
ln3_right[0,1,1,1]  0.000331
ln2_right[0,0,1,1]  0.000482
ln1_right[0,0,0,1]  0.000674
ln0      [0,0,0,0]  0.000895   ← 最差
```

可操作规则（仅本协议）：

1. **至少在前 1–2 个 block 开 LN**（比完全不开好 3–4×）。
2. 同个数时优先 **左对齐**（`[1,0,0,0]` 比 `[0,0,0,1]` 好约 3.1×）。
3. 从 2 个增到 4 个几乎不涨（0.00020 → 0.00027），**不要把“LN 最多”当成绝对最优**。

## 适用范围

- 数据：`spiralcls_8585ec`
- 架构骨架固定：`d=4, w=64, res=True, act=silu`，只改 `mask`
- 训练：`Adam lr=1e-3, steps=256, bs=32, wd=0`
- 3 seeds 均值；CE 全部 < 0.001（成功区内的相对比较）
- **位置效应只在 d=4 上直接测过**；d≠4 的“左端优先”是从 block 语义外推的假设

## 证据

同个数配对：

| 配对 | 左 CE | 右 CE | 左/右 |
|---|---:|---:|---:|
| 1 个 LN | 0.000216 | 0.000674 | 0.32 |
| 2 个 LN | 0.000203 | 0.000482 | 0.42 |
| 3 个 LN | 0.000208 | 0.000331 | 0.63 |

source 在“难语境”里则更接近“LN 越多越好”（0 个 LN 中位 CE 0.26–0.59，2–3 个 LN 掉到 0.002–0.06）。这是 **观测性对照**，不是控制变量。

## 副结论（欠训区）的独立适用范围

- **只** 指 source 弱 lr 语境（如 `Adam|3e-5`、`Adam|1e-4`）下的混池中位数趋势
- **不是** 控制实验；未单独扫 mask×lr
- 表述限于：**欠训时先保证有 LN（数量），再谈位置**；不要写成“欠训时 LN 越多越好”

## 边界

- 只测了 d=4 的 9 种 mask；没有穷举所有 2⁴ 模式。
- CE 已到 1e-4 量级，相对差的绝对值可能落在种子噪声内（C08：相对 std ~14%），但 **左 vs 右 3× 的差距大于噪声**。
- 不覆盖 RMSNorm、GroupNorm、LN 放在 Linear 前/后的其它变体。
- 不覆盖无 residual、无激活、d=1（d=1 的 mask 只有 0/1，谈不上位置）。
- 与跨族 playbook 的“选 LN 最多的 66%”不冲突：那是 **三选项选择题命中率**，这里是 **连续 CE**；题目选项里 LN 数量与位置常绑在一起。

**证伪条件**
- 主结论（成功区位置优先）：同协议下若 `ln2_right` 稳定优于 `ln2_left`（3 seeds 同向且差 >2×），或 `ln4` 显著差于 `ln2_left`（>2×），则被证伪。
- 副结论（欠训区数量优先）：若弱 lr 控制实验中 0-LN 与 2–3 LN 差距 <1.5×，则被证伪。
