# C08 · 数据集难度可造成数倍 loss 差，不能当噪声

## 结论

**范围：univar，`[0,1]` 上干净符号目标 `y=f(x)`，同配置跨数据集对比。**  
同一套架构+训练配方换 univar 数据集时，test MSE 可相差 **3–5 倍**。跨数据集比较 raw loss 会把「题目难度」误当成「模型好坏」。任何架构结论都必须 **固定数据集** 或做显式配对。

## 适用范围

- univar，目标为 `[0,1]` 上的符号函数（多项式 / 三角 / 双曲混合）。
- 证据来自多数据集重复配置：
  - `e9b`：同配置出现在 `q_0b5a9f` 与 `q_0f9cad`；
  - `fill_v1`：银行两数据集 `q_0b5a9f` / `q_0f9cad` 上的同配置补测。
- 度量：5 或 3 seeds 平均 test MSE。

## 证据

| 来源 | 多数据集配置数 | loss 差值中位数 | max/min 中位数 |
|---|---:|---:|---:|
| e9b univar | 156 | 0.38 | **3.1×** |
| fill_v1 | 65 | 0.35 | **4.5×** |

同配置例子（Adam 1e-3, 256×32, d=2, w=192, mask=(0,1), res, silu）：

- `q_0b5a9f` ≈ 0.17
- `q_0f9cad` ≈ 0.48

题面目标复杂度与难度有趋势关系但 **不是充分统计**：既有极简单目标（`x**3`）也有难的振荡目标；具体间隔还取决于 budget 与优化器。

## 边界

- 不声称难度可由表达式复杂度精确预测；本库只证明「跨数据集 raw loss 不可比」。
- 不覆盖定义域、噪声标签、分布外采样；这些题面都是干净的 `y = f(x)`。
- 分类族的 CE 量纲不同（见 arch_score 文档），更不能跨族比 raw loss。
