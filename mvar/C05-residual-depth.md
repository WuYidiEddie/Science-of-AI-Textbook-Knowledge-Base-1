# C05 · 残差：d≥4 明显有用，d≤3 接近噪声

## 结论

**在下列全 LN 基座内**，残差收益 **随深度增大**：`d=4–5` 时明显（17/20）；`d=1–3` 时接近噪声（11/20、7/10）。

**配方依赖**：C10 D1 在 d=4+全 LN 上，4 个核心配方（Adam 3e-4/1e-3/3e-3 + SGD）均为 res 更好（22/24），SGD 幅度最大（Δ≈−0.095）。本条的「深度分层」本身只在 Adam 1e-3 上测过。

## 适用范围

- **指标**：test MSE（越低越好）  
- `res_x_d`：**全 LN mask**，width=64，act=relu  
- 训练：**仅** Adam / lr=1e-3 / 256 / bs=32 / wd=0（深度分层结论）  
- depth∈{1,2,3,4,5}，res∈{True,False}  
- 10 ds × 3 seeds  
- 另：基座部分 LN（mask=[1,1,0], d=3）上的 `res_base` 主效应  
- **不**覆盖：无 LN / 部分 LN 下的残差×深度；RMSprop/Adagrad；d>5

## 证据

| 深度带 | mean(res − plain) | res 更好 |
|---|---:|---:|
| d=1 | −0.0045 | 7/10 |
| d=2–3 | −0.0031 | 11/20 |
| d=4–5 | **−0.0265** | **17/20** |

基座主效应（d=3 部分 LN）：res1 **0.48** vs res0 **0.50**（弱正）。

## 边界

- 全 LN + width=64 下测得；**部分 LN / 无 LN 时残差价值可能不同**。  
- E8 表几乎没有「只改残差」的干净配对；不要用 E8 原始均值谈残差。  
- 未测 highway 门控、未测 pre/post-norm 与残差的交互。

### 做题警示：「SGD 残差必开」勿套到 d≤3

C10 D1 的「SGD 上 res Δ≈−0.095、必开」范围是 **d=4 + 全 LN + relu**。在 **d=2** 上残差接近噪声（本表 11/20）；若激活还是 **gelu**（C10 E1：SGD 上 gelu 0.440 ≫ relu 0.372），残差救不回来。

- **反例（题对齐）**：`q_18bece`（SGD lr=3e-3 **mom=0.9**，2048×16）赢家是 **d=4 + 2LN + relu + 无残差**，胜 d=2 + res + 1LN + gelu。  
- **用法**：SGD 语境先看是否 d≥4+全 LN 再强制残差；d=2 时把 relu/leaky（非 gelu）与更多 LN 排在残差前面。
