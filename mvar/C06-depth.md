# C06 · 深度：d=1 明显差；d=2–5 在全 LN 下接近

## 结论

**在下列 Adam 1e-3 全 LN 基座内**：相对 `d=1`，`d≥3` 明显更好；`d=2…5` 彼此差距小（更深仅略占优）。  
「深就好」是 **有下界的粗规律**，不是精细排序。

**配方依赖**：C10 B1–B4 —— 深度效应在 Adam **3e-4** 最强（更深 93%），1e-3 减弱（63%），3e-3 接近消失（57%）；**SGD(mom=0.9) 上更深反而差（40%，勿选 d=5）**。本条只固定 1e-3。

## 适用范围

- **指标**：test MSE（越低越好）  
- 同 C05 的 `res_x_d` 设计（全 LN，width=64，act=relu）  
- 训练：**仅** Adam / lr=1e-3 / 256 / bs=32 / wd=0  
- 10 ds × 3 seeds  
- 不覆盖：部分 LN + 深网；width–深度联合；d>5；非 Adam 1e-3 配方的深度排序（见 C10）

## 证据

- 更深者胜：res=True **65/100 = 65%**，res=False **58/100 = 58%**（温和）。  
- d=1 均值 MSE ≈ **0.58**；d≥3 ≈ **0.47–0.49**。  
- 全 LN 时 d=2–5 均值挤在 0.47–0.50，**没有**「d=5 远好于 d=2」。

## 边界

- 与题库统计「最深赢 23/32（mvar architecture_only）」不冲突：题库选项常同时变 LN/宽度，深度是条件趋势。  
- 去掉 LN 后深度效应可能变大（容量不足时）。  
- 未测 d>5。

### 做题警示：「d=1 必差」是基座内结论，不是跨配方硬死刑

速查里的硬规则 **「d=1 必差」** 来自 cross depth（Adam {3e-4,1e-3,3e-3} 与 SGD，**全 LN，w=64**）。做题时勿写成无条件硬淘汰：

- **反例（题对齐）**：`q_9fdb97`（SGD lr=3e-3，无 mom，512×16）赢家是 `d=1,w=192,res,relu`，输给 `d=4,w=96` 的选项——**宽度大幅领先 + 高 lr 深度红利塌缩（C10 B3/B4）时，d=1 可以赢**。
- **正确用法**：
  1. 先看训练语境是否落在硬规则的配方内（全 LN、w≈64、Adam 系或该 SGD 格）。
  2. 跨语境时把「d=1」当强负项，与宽度差、LN 数、残差、lr 档一起权衡；**浅宽 + 高 lr** 组合可翻盘。
  3. 配合 C10 B3（lr=3e-3 深度优势消失）与 B4（SGD 上勿迷信深网）使用，而不是单条硬淘汰。
- **跨优化器时，(opt,lr) 可压过 d=1**：若对手在弱语境（Adagrad@1e-3、SGD+wd>0、低 lr 欠训），Adam 系可用 lr 上的 `d=1` 仍可胜。  
  **反例（题对齐）**：`q_55cd40` 赢家是 **AdamW 3e-4 + d=1 + LN**，胜 Adagrad@1e-3 更深网与 SGD@3e-3+wd=1e-3 更深网。  
  **用法**：比较三选项时 **先比 (opt,lr) 档**（C07），档内再用深度硬规则。
