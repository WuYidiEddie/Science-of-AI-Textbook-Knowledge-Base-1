# C02 · 宽度：Adam 1e-3 基座上 16–256 越宽越好

## 结论

**仅在下列训练配方与基座内**：固定其余架构因子时，width∈{16,32,64,128,256} 上测试 MSE 单调下降（更宽更好）。

**这不是**「mvar 任意配方下越宽越好」——宽度方向随优化器/lr 改变，见 [C10 A](C10-architecture-by-recipe.md)。

注意：三选一选择题里「别选最宽」是题库策略（见边界），与本条不矛盾。

## 适用范围

- **指标**：test MSE（越低越好）  
- OFAT 基座：`depth=3, mask=[1,1,0], res=True, act=relu`  
- 训练：**仅** Adam / lr=1e-3 / 256 steps / bs=32 / wd=0  
- 10 个 mvar 实例 × 3 seeds（`supp_ofat.jsonl`，`kind=width`）  
- **不**覆盖：width>256、depth×width 联合、固定参数量下的深窄 vs 浅宽、**其它优化器/lr（见 C10：RMSprop@1e-3 与 Adam@1e-2 上方向相反或失效）**

## 证据

| w | ds 平均 test MSE |
|---:|---:|
| 16 | 0.69 |
| 32 | 0.58 |
| 64 | 0.48 |
| 128 | 0.46 |
| 256 | **0.43** |

配对：更宽者胜 **85/100 = 85.0%**，平均优势 **+0.129** MSE。

对照混杂统计：`measured.jsonl` 同训练配置两两比，更宽者胜 64.4%（被深度/LN/激活混杂，方向仍偏宽）。

## 边界 / 与选择题启发式的关系

| 设计 | 现象 | 范围 |
|---|---|---|
| OFAT 扫宽 | 越宽越好 | 固定其它因子，w=16–256，Adam 1e-3/256 |
| 三选一题库（见 `arch_score/docs/how-to-pick-architecture-evidence.md`） | 「最宽」常不是答案 | 选项为相对比较，含过宽干扰项 |

- 未测 width>256；过宽后可能欠优化/过拟合。  
- 不覆盖「参数量固定时加宽减深」的权衡。  
- **已扫优化器×宽度（C10）**：Adam 3e-4/1e-3（及 b16/b64、s1024）更宽胜 72–92%；Adam 3e-3 仅 61%；Adam 1e-2 仅 44%；**RMSprop@1e-3 仅 31%（256 最差）**。本条不得外推到这些配方。  
- 换激活后的宽度单调性未单独全因子扫描。
