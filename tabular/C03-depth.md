# C03 深度：短预算 tabular CE 上浅网更好，加步数救不了深网

## 结论

在固定 `w=128、full LayerNorm、residual、gelu、Adam 1e-3、bs=32` 时，**深度越深，test CE 越差**：

| depth | mean CE（steps 池化） | 同 (ds,steps) 内 rank（最好=1） |
|---:|---:|---:|
| 1 | **0.114** | **0.907** |
| 2 | 0.146 | 0.630 |
| 3 | 0.170 | 0.407 |
| 5 | 0.195 | **0.056** |

6 个数据集里 **5 个**是 d=1 最好；唯一例外 q_8e12f6（d=2 略好，四个深度都在 0.11 附近）。

**加步数不能把深网救回来**：

| steps | d=1 | d=5 | d=5 相对 d=1 |
|---:|---:|---:|---:|
| 256 | 0.121 | 0.179 | +0.058 |
| 512 | 0.105 | 0.186 | +0.081 |
| 1024 | 0.117 | 0.220 | +0.103 |

d=5 从 256→1024 反而变差（+0.041）；d=1 在 512 步最好。故在该范围内，「深度税」不是欠训练造成的。

## 适用范围

- 任务：tabular 合成**二分类**，loss=CE
- 架构：`w=128`，mask 全 1（每层 LN），residual=True，act=gelu；d ∈ {1,2,3,5}
- 训练：Adam lr=1e-3，bs=32，wd=0，steps ∈ {256,512,1024}
- 数据：6 个合成 tabular 实例（含偏易/偏难），3 seed
- 来源：`gap_depth_steps`（72 行，受控）

## 证据

1. 受控深度阶梯（上表）——同数据集、同语境、只改 d 与 steps。
2. 历史 measured 同 ctx rank：d=2 最高（0.54），d=1 最低（0.47），**远弱于 gap**；差异说明历史库的 d 与 w/mask 混杂，浅网优势被稀释。
3. source 同 ctx rank：d=1 = 0.66 ＞ d=5 = 0.37，方向与 gap 一致。
4. 题面胜负：architecture_only 里 depth 相关对比双向都有（win=3/lose=5 等），因为选项还叠了宽度/LN/激活；**不能**用题面票数否定受控结论。

## 边界 / 不可外推

1. **仅 w=128**。更窄时深网可能更差；更宽或样本更多时未测。
2. **仅 full-LN + residual**。无残差时深网更伤；无 LN 时深网更伤（见 C04）。
3. **仅 256–1024 步**。若步数到 1e4+ 且样本变多，深度优势是否回来——**未测**，不要写进结论。
4. **仅 tabular 二分类**。回归族（univar/mvar）与 XOR 被理论认为偏深，**不要**把本条搬到那些族。
5. d=5 变差可能含优化困难与过拟合双重成分；现有数据分不开。
6. 不能说「深度无用」——只说**在本范围内深度不产生正收益**。
