## 结论写作约定

每条结论固定包含四段：

1. **结论** — 一句可检验的陈述
2. **适用范围** — 任务族、模型类、损失、超参网格、数据集、种子数；范围是结论的一部分
3. **证据** — 具体数字（配对胜率、均值差、样本数），指向数据文件
4. **边界** — 已知不成立或未验证的外推；以及与其他文档冲突时的范围差异

原则：

- **优先配对/单因子（OFAT）比较**，少用混杂的原始均值排名。
- 胜率与效应量同时给出；只有方向没有幅度的结论会降级为「倾向」。
- 若不同实验设计给出相反符号，必须写清各自的条件，不得揉成一条「规律」。
- **多规则文档**（一文多条 W/F/H/R…）里，**每条规则正文都要有「适用范围」**（可写「同本节/同 F-1」但不可省略）；文末总范围不能代替单条范围。
- cheatsheet 只做索引，须声明「范围以正文为准」。
